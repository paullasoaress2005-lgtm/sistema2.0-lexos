# LEX.OS Control 2.0

Recriação frontend do sistema LEX.OS Control usando a identidade visual do CRM LEX.OS.

## Comandos

```powershell
npm run dev
npm run build
```

## Rotas

- `/login`
- `/dashboard`
- qualquer rota interna é resolvida pelo frontend estático.

## Observação

Este projeto recria a camada visual e fluxos demonstrativos. Integrações reais, autenticação, banco e permissões devem ser conectados ao backend definitivo.
